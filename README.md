# HTMLmove

**雙擊一個 HTML，就能在瀏覽器剪片、加音樂、上字、畫箭頭；需要時還能用 AI 自動產生字幕。**

HTMLmove 延續 HTML Office 的單檔做法，把編輯器、時間軸、預覽和匯出功能放在同一個 HTML 裡。用桌面版 Chrome 或 Edge 開啟後，就能直接讀取本機素材。適合剪接約十分鐘的日常影片，例如串接多段畫面、替操作錄影加字幕，或用圓圈和箭頭標出重點。

一般剪輯不需要帳號、安裝軟體或上傳影片；**AI 字幕的辨識程式與模型則採需要時才下載**，不會塞進 HTML 檔案裡。

**[HTML Office 系列首頁](https://office.ddmmbb.org/)** 提供其他系列工具的線上體驗與離線套件。

> [!NOTE]
> AI 自動字幕為新版功能。如果開啟後沒有「AI 自動字幕」按鈕，代表使用的是尚未加入此功能的舊版 HTML。請確認下載的編輯器版本。

## 匯出影片前請先看

> [!IMPORTANT]
> **匯出時間接近影片片長。** HTMLmove 目前用瀏覽器按原速播放合成畫面，再將畫面和聲音錄製成新檔。十分鐘的影片通常要等接近十分鐘。只做裁剪或接片也會重新編碼。選擇 720p 可減輕編碼時的運算負擔。

- **解析度**預設為 720p（1280 × 720），最高為 1080p（1920 × 1080）。畫面比例為 16:9，匯出目標為 30 fps。
- **檔案格式**依瀏覽器的編碼支援而定，匯出視窗會列出可用的 MP4 或 WebM。
- **匯出期間請讓剪輯頁籤保持在前景。** 切到其他頁籤時，匯出會暫停，回到剪輯頁籤後繼續。
- **多軌會增加播放與合成的運算量。** 主影片、疊加影片、音樂、圖文和字幕會合成一支成品影片。成品大小主要取決於片長、編碼位元率與畫面內容。
- **字幕會直接繪製在匯出的影片畫面上。** 如需獨立字幕檔，也可以另外下載 SRT。

## 快速開始

1. 下載 [HTMLmove.html](HTMLmove.html)，用電腦版 Chrome 或 Edge 開啟。
2. 將影片拖進編輯器，或按素材庫的「匯入」。影片會依序放到主影片軌，音樂會放到音樂軌。
3. 拖曳片段兩端裁掉頭尾，或把播放頭移到切點後按「分割」。可以拖動主影片片段改順序，前後片段會自動接合。
4. 按「上字」或從「圖形」選擇圓圈、箭頭等標記。可直接在預覽畫面拖動、縮放與旋轉，在右側「片段設定」調整顏色、角度和顯示時間。
5. 需要 AI 字幕時，先完成主影片剪輯，再按「AI 自動字幕」，選擇辨識模型及影片實際說話的語言，產生後逐句校對。
6. 若要加子母畫面，在素材庫找到影片並按「＋ 疊加」。完成剪輯後按右上角的「匯出影片」，或使用「匯出 SRT」另外保存字幕。

播放與暫停用 `Space`，分割用 `S`，刪除選取片段用 `Delete`。

## AI 自動字幕（新版）

HTMLmove 使用 **Whisper 多語言語音辨識模型**，透過瀏覽器在本機辨識影片裡的語音。影片與音訊不需要傳到辨識伺服器，也不需要另外安裝 Python 或 Ollama。

- **按需下載。** 第一次使用 AI 字幕時，才從網路下載辨識程式及模型。模型會交由瀏覽器快取管理；快取被清除、版本變動或瀏覽器未保留資源時，可能需要重新下載。
- **兩種模型。** 預設 **Whisper Base**，較適合中文辨識；另可選 **Whisper Tiny**，通常較快，但中文準確度可能較低。
- **明確指定語言。** 預設「中文（國語／普通話）」，也能切換英文、日文、韓文等語言。使用原語辨識（`transcribe`），**不會自動把中文翻譯成英文**。
- **繁體中文。** 中文字幕預設轉換為台灣繁體中文，也可以保留模型原始輸出。轉換模組同樣是需要時才載入。
- **獨立字幕軌。** AI 產生的字幕會依辨識時間放進字幕軌，可逐句修改文字、開始時間、停留長度、字體大小、顏色、位置與旋轉角度。
- **兩種輸出。** 匯出影片時可將字幕燒錄在畫面中，也可另外下載 UTF-8 的 `.srt` 字幕檔。

> [!IMPORTANT]
> **目前 AI 只辨識「主影片」軌道的語音**，不會辨識額外的音樂軌或疊加影片軌。辨識結果與時間戳記可能有錯，尤其在背景音樂、多人同時說話、口音或音質不佳時；請在匯出前校對字幕。重新辨識會取代既有 AI 字幕，但可以使用復原。

**離線使用的範圍：** 一般剪輯、播放與影片匯出可以在不連網的情況下進行。AI 字幕首次使用需要網路下載執行程式、模型及必要的中文字形轉換模組；之後能否完全離線重用，取決於瀏覽器快取及安全限制，不能保證所有瀏覽器在 `file://` 模式下都可離線載入。

## 怎麼帶走影片或繼續剪輯？

| 要帶走什麼 | 使用方式 |
| --- | --- |
| **剪輯工具** | 帶走 `HTMLmove.html`。換一台電腦後，直接用瀏覽器開啟；AI 字幕所需的模型不包含在 HTML 內。 |
| **剪到一半的專案** | 點「儲存專案」下載 JSON，並保留原始影片和音樂。下次點「開啟專案」讀取 JSON，再重新匯入原始素材以連結。字幕文字及時間軸設定會隨專案保存。 |
| **剪好的成品** | 點「匯出影片」，下載 MP4 或 WebM。影片上的字幕會一起輸出。 |
| **獨立字幕檔** | 點「匯出 SRT」，下載可供其他播放器或剪輯工具使用的字幕檔。 |

專案 JSON 只記錄時間軸、字幕內容、素材引用和各片段設定，**不會把原始影片、音樂或 AI 模型包進 JSON**。要換電腦繼續剪輯，請把 HTML、JSON 和原始素材一起帶走。

## 目前功能

- **主影片軌**可裁剪、分割、刪除和重排片段。畫面可完整顯示，也可放大填滿後調整裁切焦點。
- **疊加影片軌**可製作子母畫面，獨立調整片段時間、影片位置、大小、旋轉角度和音量。
- **文字與圖形軌**支援文字、圓圈、箭頭、方框、三角形、勾選、叉號、星形與自訂符號。內建標記用向量路徑繪製，會依匯出尺寸重新繪製。
- **AI 字幕軌（新版）**可辨識主影片語音，自動加入逐句字幕，並可調整文字、時間與畫面位置。
- **音樂軌**可調整音樂的起點、長度和音量，與原本的影片聲音混合；音量最高可調至 300%。
- **濾鏡**提供黑白、暖棕、鮮豔和提亮，可按片段套用。主影片片段之間採直接切換。
- 支援圖片與圖形旋轉、時間軸縮放、拖曳定位、復原與重做。
- 支援匯出影片與獨立 SRT 字幕檔（新版）。

## 如何請 LLM 修改

把 `HTMLmove.html` 交給 LLM，請它先看檔案裡的維護註解。說明從哪個操作入口使用新功能、預期結果，以及需要驗證的流程。請它交付可直接開啟的完整 HTML，並保留單檔、離線剪輯及舊專案相容的原則。

> 請在「圖形」選單加一個虛線箭頭。沿用現有圖形的資料結構，讓它能拖曳、縮放和旋轉。請驗證預覽、匯出，以及儲存專案後重新開啟的結果，並提供完整的 `HTMLmove.html`。

如果修改 AI 字幕功能，請額外驗證：**中文語音固定使用原語辨識而非翻譯**、模型只在需要時下載、字幕可以逐句修改、SRT 時間碼正確，以及舊版 JSON 專案仍能開啟。

### 原始碼如何方便 LLM 接手

- **單檔內按功能分區。** 素材匯入、專案資料、時間軸、畫面合成、AI 字幕、播放與匯出各有自己的區段，優先讓 LLM 容易定位與維護。
- **專案資料與播放狀態分開。** 專案用 JSON 保存，剪接與字幕時間以秒為單位，圖形座標和大小以畫面比例為單位。
- **預覽與匯出共用畫面及音訊處理。** 修改圖形、濾鏡、音量或字幕時，可以從共同入口修改，再檢查兩邊的結果。
- **AI 模型與編輯器解耦。** 模型不嵌入 HTML，需要辨識時才載入。修改辨識流程時，請注意模型載入、音訊解碼、語言指定、字幕時間軸與繁體轉換。
- **修改後可立即檢查。** 編輯器的 CSS 和 JavaScript 都在 `HTMLmove.html` 內；AI 字幕的外部依賴另行載入。儲存後重開檔案即可測試一般剪輯，AI 辨識仍須測試實際模型下載及音訊輸入。
