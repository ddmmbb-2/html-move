# HTMLmove

**雙擊一個 HTML，就能用瀏覽器離線剪片、加音樂、上字和畫箭頭。**

HTMLmove 延續 HTML Office 的單檔做法，把編輯器、時間軸、預覽和匯出功能放在同一個 HTML 裡。用桌面版 Chrome 或 Edge 開啟後，就能直接讀取本機素材。適合剪接約十分鐘的日常影片，例如把幾段畫面接起來、替操作錄影加上文字，或用圓圈和箭頭標出重點。

**[HTML Office 系列首頁](https://office.ddmmbb.org/)** 提供其他系列工具的線上體驗與離線套件。

## 匯出影片前請先看

> [!IMPORTANT]
> **匯出時間接近影片片長。** HTMLmove 目前用瀏覽器按原速播放合成畫面，再將畫面和聲音錄製成新檔。十分鐘的影片通常要等接近十分鐘。只做裁剪或接片也會重新編碼。選擇 720p 可減輕編碼時的運算負擔。

- **解析度**預設為 720p（1280 × 720），最高為 1080p（1920 × 1080）。畫面比例為 16:9，匯出目標為 30 fps。
- **檔案格式**依瀏覽器的編碼支援而定，匯出視窗會列出可用的 MP4 或 WebM。
- **匯出期間請讓剪輯頁籤保持在前景。** 切到其他頁籤時，匯出會暫停，回到剪輯頁籤後繼續。
- **多軌會增加播放與合成的運算量。** 主影片、疊加影片、音樂與圖文會合成一支成品影片。成品大小主要取決於片長、編碼位元率與畫面內容。

## 快速開始

1. 下載 [HTMLmove.html](HTMLmove.html)，用電腦版 Chrome 或 Edge 開啟。
2. 將影片拖進編輯器，或按素材庫的「匯入」。匯入的影片會依序放到主影片軌，音樂會放到音樂軌。
3. 拖曳片段兩端裁掉頭尾，或把播放頭移到切點後按「分割」。可以拖動主影片片段改順序，前後片段會自動接合。
4. 按「上字」或從「圖形」選擇圓圈、箭頭等標記。可直接在預覽畫面拖動和縮放，在右側「片段設定」調整顏色、角度和顯示時間。
5. 若要加子母畫面，在素材庫找到影片並按「＋ 疊加」。完成剪輯後，按右上角的「匯出影片」。

播放與暫停用 `Space`，分割用 `S`，刪除選取片段用 `Delete`。

## 怎麼帶走影片或繼續剪輯？

| 要帶走什麼 | 使用方式 |
| --- | --- |
| **剪輯工具** | 帶走 `HTMLmove.html`。換一台電腦後，直接用瀏覽器開啟。 |
| **剪到一半的專案** | 點「儲存專案」下載 JSON，並保留原始影片和音樂。下次點「開啟專案」讀取 JSON，再重新匯入原始素材以連結。 |
| **剪好的成品** | 點「匯出影片」，下載 MP4 或 WebM。成品可直接用支援該格式的播放器播放。 |

專案 JSON 只記錄時間軸、素材引用和各片段設定。要換電腦繼續剪輯，請把 HTML、JSON 和原始素材一起帶走。

## 目前功能

- **主影片軌**可裁剪、分割、刪除和重排片段。畫面可完整顯示，也可放大填滿後調整裁切焦點。
- **疊加影片軌**可製作子母畫面，獨立調整片段時間、影片位置、大小和音量。
- **文字與圖形軌**支援文字、圓圈、箭頭、方框、三角形、勾選、叉號、星形與自訂符號。內建標記用向量路徑繪製，會依匯出尺寸重新繪製。
- **音樂軌**可調整音樂的起點、長度和音量，與原本的影片聲音混合。
- **濾鏡**提供黑白、暖棕、鮮豔和提亮，可按片段套用。主影片片段之間採直接切換。
- 支援時間軸縮放、拖曳定位、復原與重做。

## 如何請 LLM 修改

把 `HTMLmove.html` 交給 LLM，請它先看檔案裡的維護註解。說明從哪個操作入口使用新功能、預期結果，以及需要驗證的流程。請它交付可直接開啟的完整 HTML。

> 請在「圖形」選單加一個虛線箭頭。沿用現有圖形的資料結構，讓它能拖曳、縮放和旋轉。請驗證預覽、匯出，以及儲存專案後重新開啟的結果，並提供可離線使用的 `HTMLmove.html`。

### 原始碼如何方便 LLM 接手

- **單檔內按功能分區。** 素材匯入、專案資料、時間軸、畫面合成、播放與匯出各有自己的區段。
- **專案資料與播放狀態分開。** 專案用 JSON 保存，剪接時間以秒為單位，圖形座標和大小以畫面比例為單位。
- **預覽與匯出共用畫面及音訊處理。** 修改圖形、濾鏡或音量時，可以從共同入口修改，再檢查兩邊的結果。
- **修改後可立即檢查。** CSS 和 JavaScript 都在 `HTMLmove.html` 內，儲存後重開同一個檔案即可測試。
