# HTMLmove

**雙擊一個 HTML，就能在瀏覽器剪片、加音樂、上字、畫箭頭；支援 WebCodecs 高速匯出，需要時還能用 AI 自動產生字幕。**

HTMLmove 延續 HTML Office 的單檔做法，把編輯器、時間軸、預覽和匯出功能放在同一個 HTML 裡。用桌面版 Chrome 或 Edge 開啟後，就能直接讀取本機素材。適合剪接日常影片，例如串接多段畫面、替操作錄影加字幕，或用圓圈和箭頭標出重點。

一般剪輯不需要帳號、安裝軟體或上傳影片；**高速匯出核心（Mediabunny）與 AI 字幕模型皆採需要時才下載**，不會預先塞進 HTML 檔案裡。若有完全離線高速匯出的需求，也可在匯出視窗一鍵另存「完整離線高速版 HTML」。

**[HTML Office 系列首頁](https://office.ddmmbb.org/)** 提供其他系列工具的線上體驗與離線套件。

> [!NOTE]
> 高速匯出與 AI 自動字幕為新版功能。如果開啟後沒有「匯出引擎」選項或「AI 自動字幕」按鈕，代表使用的是舊版 HTML，請確認下載的編輯器版本。

## 匯出影片前請先看

> [!IMPORTANT]
> **新版支援 WebCodecs 高速匯出，不再受限於影片片長。** 預設為「智慧選擇」，會依專案內容與瀏覽器能力自動挑選最快的匯出方式；若瀏覽器不支援高速編碼，會自動改用原有的相容模式。

- **三種匯出引擎**：
  - **智慧選擇（推薦）**：若單一主影片未經剪裁、調色、縮放或加字，且解析度與格式相符，會直接**無損複製**（免重新編碼）；否則優先使用高速匯出，不支援時自動退回相容匯出。
  - **WebCodecs 高速匯出**：使用瀏覽器硬體加速與 Mediabunny 核心進行非即時編碼，速度取決於電腦硬體與素材，不受播放時間限制。支援**直接寫入硬碟**（推薦用於長影片，減少記憶體佔用）。
  - **MediaRecorder 相容匯出**：按原速播放畫面並錄製，匯出時間接近影片片長。使用此模式時**請讓剪輯頁籤保持在前景**，切到其他頁籤會暫停，回到頁籤後繼續。
- **離線高速版**：首次使用高速匯出需連網載入核心（核心就緒後才會要求選擇儲存位置）；點選匯出視窗內的「**製作完整離線高速版 HTML**」，即可將核心嵌入並另存為 `HTMLmove-fast-offline.html`，之後完全離線也能高速匯出。
- **解析度與格式**：預設為 720p（1280 × 720），最高為 1080p（1920 × 1080），畫面比例 16:9，匯出為 30 fps。格式支援 MP4 或 WebM（依瀏覽器編碼器支援而定）。
- **字幕輸出**：字幕會直接繪製在匯出的影片畫面上；如需獨立字幕檔，也可以另外下載 SRT。

## 快速開始

1. 下載 [HTMLmove.html](HTMLmove.html)，用電腦版 Chrome 或 Edge 開啟。
2. 將影片拖進編輯器，或按素材庫的「匯入」。影片會依序放到主影片軌，音樂會放到音樂軌，圖片會放到圖文與圖片軌。
3. 拖曳片段兩端裁掉頭尾，或把播放頭移到切點後按「分割」。可以拖動主影片片段改順序，前後片段會自動接合。
4. 按「上字」或從「圖形」選擇圓圈、箭頭等標記。可直接在預覽畫面拖動、縮放與旋轉，在右側「片段設定」調整顏色、角度和顯示時間。
5. 需要 AI 字幕時，先完成主影片剪輯，再按「AI 自動字幕」，選擇辨識模型及影片實際說話的語言，產生後逐句校對。
6. 若要加子母畫面，在素材庫找到影片並按「＋ 疊加」。完成剪輯後按右上角的「匯出影片」（高速模式可勾選直接寫入硬碟），或使用「匯出 SRT」另外保存字幕。

播放與暫停用 `Space`，分割用 `S`，刪除選取片段用 `Delete`，微調影格用 `←` / `→`。

## AI 自動字幕

HTMLmove 使用 **Whisper 多語言語音辨識模型**，透過瀏覽器在本機辨識影片裡的語音。影片與音訊不需要傳到辨識伺服器，也不需要另外安裝 Python 或 Ollama。

- **按需下載。** 第一次使用 AI 字幕時，才從網路下載辨識程式及模型。模型會交由瀏覽器快取管理；快取被清除、版本變動或瀏覽器未保留資源時，可能需要重新下載。
- **兩種模型。** 預設 **Whisper Base**，較適合中文辨識；另可選 **Whisper Tiny**，通常較快，但中文準確度可能較低。
- **明確指定語言。** 預設「中文（國語／普通話）」，也能切換英文、日文、韓文等語言。使用原語辨識（`transcribe`），**不會自動把中文翻譯成英文**。
- **繁體中文。** 中文字幕預設轉換為台灣繁體中文，也可以保留模型原始輸出。轉換模組同樣是需要時才載入。
- **獨立字幕軌。** AI 產生的字幕會依辨識時間放進字幕軌，可逐句修改文字、開始時間、停留長度、字體大小、顏色、位置與旋轉角度。
- **兩種輸出。** 匯出影片時可將字幕燒錄在畫面中，也可另外下載 UTF-8 的 `.srt` 字幕檔。

> [!IMPORTANT]
> **目前 AI 只辨識「主影片」軌道的語音**，不會辨識額外的音樂軌或疊加影片軌。辨識結果與時間戳記可能有錯，尤其在背景音樂、多人同時說話、口音或音質不佳時；請在匯出前校對字幕。重新辨識會取代既有 AI 字幕，但可以使用復原。

**離線使用的範圍：** 一般剪輯、播放與相容模式匯出皆可完全離線進行。高速匯出首次使用需連網下載 Mediabunny 核心，但可透過「製作完整離線高速版 HTML」封裝成永久離線單檔。AI 字幕首次使用需要網路下載執行程式、模型及中文字形轉換模組；之後能否離線重用，取決於瀏覽器快取與 `file://` 安全限制。

## 怎麼帶走影片或繼續剪輯？

| 要帶走什麼 | 使用方式 |
| --- | --- |
| **剪輯工具** | 帶走 `HTMLmove.html`（或另存的離線高速版 `HTMLmove-fast-offline.html`）。換一台電腦後直接用瀏覽器開啟；AI 字幕模型不包含在 HTML 內。 |
| **剪到一半的專案** | 點「儲存專案」下載 JSON，並保留原始影片和音樂。下次點「開啟專案」讀取 JSON，再重新匯入原始素材以連結。字幕文字及時間軸設定會隨專案保存。 |
| **剪好的成品** | 點「匯出影片」，下載或直接寫入硬碟保存 MP4／WebM。影片上的字幕會一起輸出。 |
| **獨立字幕檔** | 點「匯出 SRT」，下載可供其他播放器或剪輯工具使用的字幕檔。 |

專案 JSON 只記錄時間軸、字幕內容、素材引用和各片段設定，**不會把原始影片、音樂或 AI 模型包進 JSON**。要換電腦繼續剪輯，請把 HTML、JSON 和原始素材一起帶走。

## 目前功能

- **高速匯出與備援（新版）**：支援 WebCodecs 高速編碼（Mediabunny 核心）、直接寫入硬碟、未剪輯影片無損複製、一鍵製作離線高速版 HTML，以及 MediaRecorder 相容模式備援。
- **主影片軌**：可裁剪、分割、刪除和重排片段。畫面可完整顯示，也可放大填滿後調整裁切焦點。
- **疊加影片軌**：可製作子母畫面，獨立調整片段時間、影片位置、大小、旋轉角度和音量。
- **文字與圖形軌**：支援文字、圖片、圓圈、箭頭、方框、三角形、勾選、叉號、星形與自訂符號。內建標記用向量路徑繪製，會依匯出尺寸重新繪製。
- **AI 字幕軌**：可辨識主影片語音，自動加入逐句字幕，並可調整文字、時間與畫面位置，另支援匯出 SRT。
- **音樂軌**：可調整音樂的起點、長度和音量，與原本的影片聲音混合；音量最高可調至 300%。
- **濾鏡**：提供黑白、暖棕、鮮豔和提亮，可按片段套用。主影片片段之間採直接切換。
- 支援圖片與圖形旋轉（按住 Shift 每 15° 定位）、時間軸縮放、拖曳定位、復原與重做。

## 如何請 LLM 修改

把 `HTMLmove.html` 交給 LLM，請它先看檔案裡的維護註解。說明從哪個操作入口使用新功能、預期結果，以及需要驗證的流程。請它交付可直接開啟的完整 HTML，並保留單檔、離線剪輯及舊專案相容的原則。

> 請在「圖形」選單加一個虛線箭頭。沿用現有圖形的資料結構，讓它能拖曳、縮放和旋轉。請驗證預覽、高速與相容匯出，以及儲存專案後重新開啟的結果，並提供完整的 `HTMLmove.html`。

- 若修改**匯出功能**：請保留 `MEDIABUNNY_BUNDLE_BEGIN` / `END` 單檔封裝標記，並確認核心載入完成前不會開啟選檔視窗，以及高速模式與相容模式皆能正常輸出。
- 若修改**AI 字幕功能**：請驗證中文語音固定使用原語辨識而非翻譯、模型只在需要時下載、字幕可逐句修改、SRT 時間碼正確，以及舊版 JSON 專案仍能開啟。

### 原始碼如何方便 LLM 接手

- **單檔內按功能分區。** 素材匯入、專案資料、時間軸、畫面合成、播放、高速／相容匯出與 AI 字幕各有獨立區段，方便定位與維護。
- **專案資料與播放狀態分開。** 專案用 JSON 保存，剪接與字幕時間以秒為單位，圖形座標和大小以畫面比例為單位。
- **預覽與兩種匯出共用場景渲染。** `drawScene` 同時服務預覽、WebCodecs 高速匯出與 MediaRecorder 相容匯出；修改圖形、濾鏡或字幕時只需改共同入口。
- **外部依賴解耦。** 高速匯出核心（Mediabunny）與 AI 字幕模型皆為按需載入，不影響純離線剪輯與專案結構。
